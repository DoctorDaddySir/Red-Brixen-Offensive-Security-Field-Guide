# Manual reporting references

Choose the document for the intended recipient. These are editable references; no RB command, database, workspace layout or automation is required.

| Need | Reference |
| --- | --- |
| Client engagement deliverable | [Professional report template](client-report-template.md) |
| One technical finding | [Finding template](../exploited-vulns/_TEMPLATE/finding_template.md) |
| Exam preparation/report structure | [OSCP exam template](../OSCP_NOTES/6%20-%20reporting/oscp-report-template.md) |
| Exam working notes | [Exam notes worksheet](../OSCP_NOTES/5%20-%20misc/reporting_templates.md) |
| Scope and restoration record | [Manual checklist](../methodology/scope-and-cleanup.md) |

Copy the selected template into your preferred editor. Complete bracketed instructions with actual observations, remove inapplicable sections with a reason, and retain limitations. Do not convert an untested possibility into a finding or assume a successful compromise. Record commands actually executed, the shell/host/account, relevant output and interpretation; a command copied from a reference is not evidence of execution.

Before delivery, read the rendered document, check screenshot legibility and evidence references, reconcile finding IDs and severity totals, and confirm the intended recipients and handling. Keep reusable secrets and private operator notes outside the standard client report. Use a separately agreed restricted appendix only when needed. Review attachment contents and metadata individually; removing a password from report text does not redact an attached file.

Existing exam and finding paths remain valid. The professional report is a new separate template; exam proof/submission conventions do not apply to client engagements. Updating a template does not rewrite earlier reports. The templates have been checked as Markdown; a particular editor's PDF layout or an exam upload has not been validated.
